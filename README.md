# Shipping & E-Commerce Project

## Project Overview
This project is a **Shipping & E-commerce System** that allows an admin to manage products and users to browse and purchase products. The system simulates a small-scale e-commerce platform with product management, shopping, and order tracking features.

It demonstrates **CRUD operations**, **user role management**, and basic **order and shipping functionality**.

---

## Features

### Admin Features
- Add, update, and delete products  
- Manage product inventory  
- View all orders and shipping status  
- Role-based access control  

### User Features
- Browse products by category or search  
- Add products to cart and place orders  
- View order history and shipping status  

### General Features
- Product details including name, price, quantity, and description  
- Secure login for admin and users  
- Basic shipping tracking system  

---

## Technologies Used
- **Backend:** C# / .NET Core 
- **Database:** SQL
